# 🌐 Desafio de Site HTML

Projeto desenvolvido para praticar os fundamentos do desenvolvimento web com HTML e CSS.

## 🎯 Objetivo

Praticar a criação e a estruturação de páginas web, aplicando conceitos básicos de HTML e estilização com CSS.

## 🛠️ Tecnologias utilizadas

- HTML5
- CSS3

## 📚 Aprendizados

- Estrutura básica de uma página HTML.
- Organização de elementos e conteúdo.
- Estilização de páginas com CSS.
- Prática de desenvolvimento web.

## ▶️ Como executar

1. Baixe ou clone este repositório.
2. Abra a pasta do projeto.
3. Localize o arquivo HTML principal.
4. Abra-o no navegador.
